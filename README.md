# रियाज़ (Riyaz)

Hindustani classical music practice app for a young learner —
**Guru: Viraj Salvi · Gwalior Gharana**.

Sargam notation (Devanagari) for **अलंकार**, **ताल** and **राग**, with a line that
runs along the notation as the recording plays.

- Audio/video is **streamed from Google Drive** (kept out of the repo to stay light).
- Pure static HTML/CSS/JS — served by GitHub Pages.

Live: https://akshaybangalorekar.github.io/riyaz/

Part of the Gurukool family: https://akshaybangalorekar.github.io/Gurukool/
