# रियाज़ (Riyaz)

Hindustani classical music practice app for a young learner —
**Guru: Viraj Salvi · Gwalior Gharana**.

### What's inside
- **अलंकार / ताल / राग** — sargam notation (Devanagari) with a line that runs along
  as the recording plays. Audio/video streams from Google Drive (kept out of the repo).
- **सुर पेटी** — an on-screen harmonium. Tap or use the laptop keys (a w s e d f t g y h u j k),
  pick your सा, and a तानपूरा drone to practise against. Sound is synthesised in the browser.
- **तबला** — a theka machine: choose a taal, set the BPM, and it plays the ठेका.
  Variations (अंत में तिरकिट / दुगुन / बदलता हुआ) let a learner keep taal while the
  tabla changes. Beats are shown as a grid with सम / ताली / खाली marks.

Pure static HTML/CSS/JS — served by GitHub Pages.
